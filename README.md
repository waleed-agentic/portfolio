# Waleed Ahmad Portfolio

## EmailJS Contact Form

1. Create a free account at https://www.emailjs.com/.
2. Add an Email Service and connect Gmail: waleed.ml.ds@gmail.com.
3. Create an Email Template with the variables `{{name}}`, `{{email}}`, and `{{message}}`.
4. Copy the Service ID, Template ID, and Public Key into `.env.local`.
5. Restart the dev server after adding the env values.

## Run Locally

```bash
npm run dev
```
